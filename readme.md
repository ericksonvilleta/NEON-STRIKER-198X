# NEON STRIKER: 198X 🚀⚡

A fast-paced, action-packed retro space shooter arcade game built from scratch using HTML5 Canvas, Vanilla JavaScript, and the Web Audio API. Pilot your fighter ship through waves of neon alien armadas, dodge enemy fire, collect powerful weapon upgrades, and unleash screen-clearing smart bombs!

---

## ✨ Features

- **Classic Arcade Gameplay:** Fast-moving combat, wave progressions, enemy dive-bombing AI, and boss scaling.
- **Weapon & Shield Systems:** Upgrade your lasers from single shots to multi-directional spreads and collect bombs to wipe the screen.
- **Procedural Retro Web Audio:** Built-in Web Audio API sound effects and synthesizer feedback (laser zaps, explosions, power-ups, and bomb detonations) without any external audio files.
- **Aesthetic CRT & Neon Styling:** Glowing vector graphics, particle explosion effects, custom starfields, and authentic CRT scanline visual overlays.

---

## 🕹️ Controls

| Action | Control Key / Input |
| :--- | :--- |
| **Move Ship** | `Arrow Keys` or `WASD` |
| **Fire Lasers** | `Spacebar` (Hold for continuous fire) |
| **Trigger Smart Bomb** | `Key B` |

---

## 🛠️ Technology Stack

- **HTML5 Canvas:** High-performance 2D rendering for real-time game entities and particles.
- **Vanilla JavaScript (ES6+):** Custom game loop, collision detection, and state machine.
- **Web Audio API:** Zero-dependency synthetic sound effects engine.
- **CSS3:** Glassmorphism UI, CRT scanline filters, and neon box-shadow glows.

---

## 🚀 Getting Started

To run the game locally on your computer:

1. Clone or download this repository.
2. Save the code into a file named `index.html`.
3. Open `index.html` in any modern web browser (Google Chrome, Firefox, Edge, Safari).
4. Click **"INSERT COIN"** and enjoy!
